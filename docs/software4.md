# 软件四 —— 双通道正弦信号参数测量

> 状态：**仅文档与接口骨架**。本仓库当前尚未配置任何 ADC / TIM / DMA / UART / LCD / 按键外设，
> 也未实现任何算法。文中所有 `TBD` 项均由作者在后续手工配置后填写。

## 1. 作业要求

对两路 1 kHz 正弦输入信号做一次性的同步采集与参数测量：

1. 由 TIM 定时触发、单个 ADC 以规则组（regular group）方式轮询两个通道进行采样。
2. 每个通道每个信号周期采样 400 点，一次采集覆盖 2 个周期。
3. 采样数据由 DMA 搬运到内存缓冲区，不使用逐点中断读取。
4. 按键触发一次完整采集。
5. 通过 UART 把完整采样数据发出，供 VOFA+ 等上位机绘图。
6. 在 LCD 上显示：
   - CH1 / CH2 峰峰值电压（Vpp）
   - CH1 / CH2 直流偏置（DC offset）
   - 两路信号相位差（单位：度）
7. 相位差必须使用课程要求的**积化和差 / 正交分解**方法计算，而不是简单的过零比较。

## 2. 派生采样参数

信号频率 `f = 1 kHz`，每周期每通道 `N = 400` 点，故序列触发率为 `f × N`。

| 项目 | 符号 | 目标值 | 说明 |
| --- | --- | --- | --- |
| 输入信号频率 | `f` | 1 kHz | 两路同频正弦 |
| 每通道每周期采样点数 | `N` | 400 点 | 每 2.5 µs 一个点 |
| 序列触发率 | `fs = f × N` | 400 kHz | TIM 更新事件触发 ADC |
| 触发间隔 | `Ts = 1/fs` | 2.5 µs | 也是同一通道相邻采样点的间隔 |
| 采集周期数 | `M` | 2 个周期 | — |
| 每通道采样点数 | `N × M` | 800 点 | 单次采集 |
| 通道数 | — | 2 | CH1 / CH2 |
| ADC 转换结果总数 | `N × M × 2` | 1600 | 缓冲区总容量（按 `uint16_t` 计 3200 B） |
| 单次采集时间窗口 | `M / f` | 2 ms | 800 × 2.5 µs |
| 触发定时器计数周期 | `Ts` | 2.5 µs | TIM 计数频率与 ARR 待定，见下 |

### 2.1 实现时必须核对的时序预算

单 ADC、双通道、规则组扫描，一次触发内要依次完成 2 次转换，因此：

- 若**一次触发转换 2 个通道**：相邻两次触发间隔 2.5 µs，单次转换预算仅 **1.25 µs**
  （含采样时间 + 12 位转换时间），ADC 时钟与采样时间需据此选型。
- 若改为**两通道交替触发**：序列触发率需提高到 800 kHz，才能保证每通道 400 kHz。

两种方案的选择属于实现决策，本次不预设，标记为 `TBD`。

### 2.2 电压换算

12 位 ADC，码值 `code ∈ [0, 4095]`：

```text
V = code / 4095 × VREF+
```

`VREF+` 与前端衰减/偏置电路的换算系数：`TBD`（依赖实际硬件与标定）。

## 3. 预期数据流

```text
KEY 按下
   │
   ▼
acquisition: 启动一次采集（重置 DMA 计数、使能 TIM 触发）
   │
   ▼
TIM 更新事件 (400 kHz) ──► ADC 规则组 (CH1, CH2) ──► DMA ──► 采样缓冲区
   │
   ▼
DMA 传输完成 (1600 个结果) ──► 采集完成标志
   │
   ├──► signal_analysis: DC offset / Vpp / 相位差（积化和差 + 正交）
   │          │
   │          └──► ui: LCD 显示六项数值
   │
   └──► uart_stream: 完整 1600 点数据帧 ──► VOFA+ 上位机
```

约束：UART 输出与 LCD 刷新都在主循环内完成，不得阻塞下一次采集触发；
采集缓冲区在数据被分析、发送完毕前不能被新的采集覆盖（双缓冲或"忙"标志，`TBD`）。

## 4. 规划模块

| 模块 | 文件 | 职责 | 依赖 |
| --- | --- | --- | --- |
| `acquisition` | `Core/Inc/acquisition.h`、`Core/Src/acquisition.c` | TIM / ADC / DMA 采集接口，持有采样缓冲区的所有权 | 无（内部使用 HAL） |
| `signal_analysis` | `Core/Inc/signal_analysis.h`、`Core/Src/signal_analysis.c` | 直流偏置、峰峰值、相位差算法，纯计算 | 只依赖 `acquisition` 的数据视图 |
| `uart_stream` | `Core/Inc/uart_stream.h`、`Core/Src/uart_stream.c` | 把整帧采样数据按上位机可解析的格式输出 | `acquisition` 的数据视图 |
| `ui` | `Core/Inc/ui.h`、`Core/Src/ui.c` | LCD 初始化与数值显示 | `signal_analysis` 的结果结构 |
| `key` | `Core/Inc/key.h`、`Core/Src/key.c` | 按键扫描、去抖、事件上报 | 无 |

`main.c` 只做三件事：调用各模块 `*_init()`、轮询按键事件、把结果分发给 `ui` / `uart_stream`。
