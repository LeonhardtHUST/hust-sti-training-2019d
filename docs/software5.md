# 软件五 —— 基于 AD9959 的简易电路特性测试

> 状态：**仅文档与接口骨架**。DDS 通信、扫频算法、测量编排、绘图均未实现。
> 涉及具体外设的条目一律标记 `TBD`，由作者手工配置后填写。

## 1. 对软件四的依赖

软件五不是独立工程，而是在软件四骨架上继续叠加：

| 软件四提供 | 软件五如何使用 |
| --- | --- |
| `acquisition`：TIM 触发的双通道 DMA 采集 | 原样复用。DDS 输出接被测电路输入，ADC 两通道分别测电路输入/输出 |
| `signal_analysis`：直流偏置、幅度、相位算法 | 原样复用。扫频只需要其中的**幅度**，相位可选记录 |
| `uart_stream`：整帧采样数据输出 | 复用做调试波形；扫频结果另行输出（格式 `TBD`） |
| `ui`：LCD 数值显示 | 扩展一个"扫频结果 / 幅频曲线"显示页 |
| `key`：按键事件 | 扩展第二个事件（单次测量 / 启动扫频） |

结论：**软件五的增量只应落在 `dds` 与 `measurement` 两个模块**，加上 `ui`、`key`、`uart_stream`
里少量扩展点。若发现需要改动 `acquisition` 的接口，说明软件四的接口设计有问题，应先回头修接口。

## 2. 复用边界

- `signal_analysis` 的输入仍然是"一帧两通道采样数据"，软件五**不引入新的采样通路**。
- 扫频过程中的每一次频点测量 = 一次软件四式的采集 + 一次幅度提取。
- 因此软件五不复制采集代码，只做循环编排（见第 4 节状态机）。

## 3. AD9959 DDS 集成边界

`dds` 模块**只负责"把频率/相位/幅度写进芯片"**，不含任何测量策略：

| 属于 `dds` | 不属于 `dds` |
| --- | --- |
| SPI（或并口）底层收发时序 | 扫频点如何选取 |
| 寄存器/通道地址映射、写保护解锁 | 何时切换频点 |
| 频率调谐字（FTW）换算 | 幅度如何换算成被测电路增益 |
| 通道选择与使能 | 稳定等待时间策略 |
| 幅度/相位标度写入 | 结果存储与曲线拟合 |

接口形态（见 `Core/Inc/dds.h`）：`dds_init()` / `dds_set_frequency()` / `dds_set_amplitude()` /
`dds_is_ready()`。所有函数当前均为占位实现，返回"未就绪 / 失败"。

待定项：SPI 实例与引脚、`CS` / `SCLK` / `SDIO0..3` / `IO_UPDATE` / `RESET` 的 GPIO 分配、
参考时钟来源（板载晶振 or 外部）、通道到"被测电路输入端"的对应关系 —— 全部 `TBD`。

## 4. 测量状态机概念

`measurement` 是软件五唯一的编排者，主循环只需周期调用 `measurement_poll()`：

```text
IDLE ──(按键/命令)──► SET_FREQ ──► SETTLE ──► ACQUIRE ──► ANALYZE ──► STORE
                          ▲                                              │
                          │                                              ▼
                          └────────── NEXT_POINT ◄──(还有频点)──── 判断
                                                                        │
                                                              (频点用尽) ▼
                                                                     REPORT ──► IDLE
```

- `SET_FREQ`：调 `dds_set_frequency()`，无阻塞返回。
- `SETTLE`：等待 DDS 输出与被测电路建立（延时或计数，`TBD`）。
- `ACQUIRE`：调 `acq_start()`，轮询 `acq_is_done()`，**不阻塞等待**。
- `ANALYZE`：从帧中提取该频点的输入/输出幅度。
- `STORE`：写入结果数组；容量上限 `MEASUREMENT_MAX_POINTS`。
- 任意状态可被 `ABORT` 打断回到 `IDLE`；错误统一进 `ERROR` 并保留已完成的数据点。

状态机全部在主循环里跑，中断里只置标志位，避免在 ISR 中调用 DDS / UART。

## 5. 对数扫频概念

线性扫频在宽频带内低频点过稀、高频点过密，因此采用**对数（等比）频率轴**：

```text
f_k = f_min × (f_max / f_min)^(k / (K − 1)),  k = 0 … K−1
```

- 每十倍频程点数 `P`（`TBD`，例如 20）：
  `K = floor(P × log10(f_max / f_min)) + 1`
- 相邻点比值：`f_{k+1} / f_k = (f_max / f_min)^(1/(K−1))`，恒定。
- 绘制时横轴取 `log10(f)`，曲线才是标准幅频特性形状。
- `f_min` / `f_max` / `P` 均 `TBD`，取决于被测电路与题目指标。

实现注意：`powf()` / `log10f()` 来自 `<math.h>`，会引入浮点库，需要确认链接与栈开销（`TBD`）。
若不希望引入浮点库，可用查表或定点迭代，属于实现选择。

## 6. 幅频响应工作流

```text
设置频点 f_k ──► DDS 输出正弦 ──► 被测电路 ──► ADC 采集 (输入 CH?, 输出 CH?)
                                                    │
                                                    ▼
                                        Vpp_in(f_k), Vpp_out(f_k)
                                                    │
                                                    ▼
                          gain_dB(k) = 20 × log10( Vpp_out / Vpp_in )
                                                    │
                                                    ▼
                                    存入 measurement_point_t 数组
                                                    │
                              (全部频点完成) ──► 输出 / 显示 / 上位机绘图
                                                    │
                                                    ▼
                         由曲线求上限截止频率 fH（−3 dB 点）等派生量
```

- 幅度取**峰峰值**而非单点采样，抗噪更好，复用 `signal_analysis` 的 Vpp。
- 相位可顺带记录，但增益与截止频率只依赖幅度。
- `−3 dB` 点求解：在幅频数据上查找 `gain_dB` 首次低于 `gain_mid − 3 dB` 的区间，再线性/对数插值。
  具体判据（以中频增益为基准还是以 0 dB 为基准）`TBD`。

## 8. 三类工作的分界

### 8.1 作业要求（必须实现）

- AD9959 输出可控频率的正弦信号，驱动被测电路。
- 按键触发一次自动化测量流程。
- 完成 2019D「简易电路特性测试仪」要求的测量项目与显示（具体指标以题目原文为准，
  常见项包括：输入电阻、输出电阻、增益、幅频特性曲线与上限截止频率）。
- 幅频特性采用对数频率轴扫频获得。
- 结果在 LCD 上显示（或按题目要求的方式呈现）。

### 8.2 课程 / 参考设计思路（非强制，可替换）

- 用状态机而非阻塞延时串起"设频 → 稳定 → 采集 → 计算"。
- 复用软件四的双通道同步采集，一次采集同时拿到输入与输出幅度。
- 用峰峰值作为幅度度量，用积化和差/正交法顺带取相位。
- 扫频在中频段加密、在两端稀疏（非均匀对数分布）。
- `−3 dB` 点用相邻两点插值而非取最近点。

### 8.3 可选扩展（有余力再做）

- 扫频结果通过 UART 上传，PC 端绘 Bode 图。
- 自动化故障判定（元件开路/短路识别），按题目要求输出结论。
- 多次采集取平均以抑制噪声，或对 Vpp 做滑动中值滤波。
- 校准表：对 DDS 输出幅度随频率的跌落做补偿。
- 扫频过程可视化进度条。

> 以上扩展均不在本次初始化范围内。
